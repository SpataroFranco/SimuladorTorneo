# ⚽ Simulador de Torneo

Simulador de torneos de fútbol desarrollado en Python con una interfaz visual interactiva.

El sistema permite crear equipos profesionales y amateurs, generar torneos automáticamente, simular partidos y visualizar estadísticas, resultados y tablas de posiciones en tiempo real.

---

# 🌐 Demo Online

https://nicholasaira.github.io/SimuladorTorneo/

---

# 🚀 Funcionalidades

- Creación de equipos personalizados
- Equipos profesionales y amateurs
- Simulación automática de torneos
- Tabla de posiciones dinámica
- Registro de partidos y resultados
- Estadísticas del torneo
- Visualización del campeón
- Integración con API Football
- Interfaz web interactiva

# 📦 Instalación

Clonar el repositorio:

```bash
git clone https://github.com/SpataroFranco/SimuladorTorneo.git
```

Ingresar a la carpeta del proyecto:

```bash
cd SimuladorTorneo
```

Instalar dependencias:

```bash
pip install requests python-dotenv
```

---

# 🔑 Configuración de la API

Crear un archivo `.env` en la raíz del proyecto y agregar:

```env
API_FOOTBALL_KEY=TU_API_KEY
```

---

# ▶️ Ejecución

Ejecutar el proyecto con:

```bash
python src/main.py
```
